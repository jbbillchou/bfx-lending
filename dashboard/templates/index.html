    年化報酬率 = 以最早可用的資產快照為基準，將累積收益換算成年化百分比

    Σ(快照日後收益) ÷ 快照日總市值 × (365 ÷ 經過天數) × 100

    總放貸：--

    有效年化 = 使用率 × 放貸利率，以總餘額為分母衡量整體資金效率

    Σ(放貸金額 × 利率) ÷ 總餘額 = (放貸額 ÷ 總餘額) × 加權放貸利率

    使用率偏低會拉低有效年化，即使放貸利率很高。兩個數字一起看，才能判斷是「利率問題」還是「閒置問題」。

    通知設定（Telegram）

    ① 取得 Bot Token

    1. 在 Telegram 搜尋 @BotFather
    2. 輸入 /newbot，依提示設定 Bot 名稱
    3. BotFather 回傳的 token 格式：123456789:AAFxxx...

    ② 取得 Chat ID

    1. 先對你的 Bot 傳一則任意訊息
    2. 在瀏覽器開啟：https://api.telegram.org/bot<TOKEN>/getUpdates
    3. 在回傳 JSON 中找 "chat" → "id"，即為 Chat ID

    填入後點「測試推播」，手機收到訊息即代表設定正確。

    推播通知設定請至「推播」頁籤管理。

    久未成交自動降保底請至「利率設定」頁籤管理。

    推播通知設定

    Telegram Bot Token 與 Chat ID 請在「設定」頁籤中設定。
